# Pan-Cancer Analysis of ABC Transporter Genes

## Project Overview

This project performs a comprehensive analysis of ABC (ATP-binding cassette) transporter genes across multiple cancer types using data from The Cancer Genome Atlas (TCGA). The analysis investigates the differential expression of these genes between tumor and normal tissues and their association with patient survival outcomes.

The core of this project involves:
1.  Processing raw gene expression data to focus on 49 selected ABC transporter genes.
2.  Performing pan-cancer and per-cancer differential expression analysis using DESeq2.
3.  Conducting survival analysis (OS, DSS, DFI, PFI) for each gene in each cancer type.
4.  Generating visualizations such as volcano plots, heatmaps, and Kaplan-Meier survival curves to summarize the findings.

## Data Files

*   `merged_rawcounts.csv`: A CSV file containing the raw gene counts from a pan-cancer RNA-seq dataset. The first column contains Ensembl gene IDs.
*   `TCGA-CDR-SupplementalTableS1.xlsx`: An Excel file containing curated clinical data for the TCGA cohorts, including survival information (OS, DSS, DFI, PFI) and patient metadata. This is used to associate expression data with clinical outcomes.
*   `Survival_Data.csv`: The output CSV file generated by the main analysis script. It contains the results of the Cox proportional-hazards model for each gene in each cancer, including hazard ratios and p-values.

## Analysis Workflow

The entire analysis is orchestrated by the `ABC_gene-analysis.R` script. The workflow is as follows:

### 1. Data Preparation
- Raw gene counts are loaded from `merged_rawcounts.csv`.
- Ensembl gene IDs are mapped to HGNC gene symbols using the `biomaRt` package.
- The dataset is filtered to retain only a predefined list of 49 ABC transporter genes.
- Sample metadata (`coldata`) is created by parsing TCGA barcodes to distinguish "Tumor" from "Normal" samples.

### 2. Pan-Cancer Differential Expression
- A differential expression analysis is performed on the full dataset using `DESeq2` to compare tumor vs. normal samples.
- A volcano plot (`plots/ABC_volcano plot.png`) is generated from these results to visualize up- and down-regulated genes.

### 3. Per-Cancer Differential Expression and Normalization
- The script iterates through 15 different cancer types (e.g., BLCA, BRCA, COAD).
- For each cancer type:
    - A subset of the count data is created.
    - A separate `DESeq2` analysis is run to find differentially expressed genes within that cancer.
    - The expression data is normalized using Variance Stabilizing Transformation (VST) for use in survival analysis.

### 4. Heatmap of Differentially Expressed Genes
- The results from the per-cancer DESeq2 analyses are combined.
- A heatmap (`plots/heatmap_pancan.png`) is generated to show the log2 fold change of significantly expressed genes across all analyzed cancer types. The heatmap is filtered to only show genes with a |log2FC| > 1.5 in at least one cancer.

### 5. Survival Analysis
- For each cancer type, the normalized gene expression data is merged with the clinical survival data.
- Patients are stratified into "High" and "Low" expression groups based on the median expression of each gene.
- Cox proportional-hazards models are used to assess the association between gene expression and four types of survival outcomes:
    - **OS**: Overall Survival
    - **DSS**: Disease-Specific Survival
    - **DFI**: Disease-Free Interval
    - **PFI**: Progression-Free Interval
- The results (hazard ratio, p-value) are compiled into `Survival_Data.csv`.

### 6. Generation of Kaplan-Meier Plots
- The script filters the survival results for statistical significance (p < 0.05) and a meaningful effect size (HR > 1.5 or < 0.6).
- For each significant finding, a Kaplan-Meier survival plot is generated using `survminer` and saved as a PNG file in the `plots/Survival_plots/` directory, organized by cancer type and survival type.

## R Dependencies

To run the analysis, you will need the following R packages:

- `janitor`
- `dplyr`
- `data.table`
- `biomaRt`
- `DESeq2`
- `stringr`
- `ggplot2`
- `ComplexHeatmap`
- `EnhancedVolcano`
- `survival`
- `survminer`
- `openxlsx`

You can install them using `install.packages()` and `BiocManager::install()` for Bioconductor packages.

## How to Run the Analysis

1.  **Set up the environment**:
    - Make sure all required R packages are installed.
    - Place the necessary data files (`merged_rawcounts.csv`, `TCGA-CDR-SupplementalTableS1.xlsx`) in the root directory.

2.  **Execute the script**:
    - Open `ABC_gene-analysis.R` in an R environment (like RStudio).
    - Set the working directory to the project's root folder using `setwd("/path/to/your/project")`.
    - Run the script from top to bottom.

The script will automatically generate the `plots` directory, the `Survival_Data.csv` file, and all the corresponding image files.
